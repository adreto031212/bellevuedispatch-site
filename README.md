# bellevuedispatch.com

Static landing site for the Bellevue Dispatch newsletter (GitHub Pages). Generated by `site/bellevuedispatch/build.py` in the RexMont ai-ops repo. Edit there, rebuild, push here. The signup form posts to the n8n webhook `bellevue-dispatch-signup`, which creates the beehiiv subscription with custom fields; beehiiv double opt-in → n8n → Follow Up Boss.
